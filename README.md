# Ejercicio

Ejercicio práctico de control de versiones con Git: creación de ramas, commits y fusión de cambios.

## Contenido

- `README.md` — cambios realizados en la rama `master`
- `README2.md` — cambios realizados en la rama `develop`

Este repositorio documenta, a modo de práctica, el flujo de trabajo con ramas en Git (creación de una rama, commits independientes y fusión de los cambios).
