# Ejercicio — Flujo de ramas con Git

![Git](https://img.shields.io/badge/Git-F05032?style=flat&logo=git&logoColor=white)

Práctica de control de versiones con Git: creación de ramas, commits independientes en cada una y fusión de los cambios.

## Contenido

| Archivo | Descripción |
|---|---|
| `README.md` | Documentación del ejercicio. |
| `README2.md` | Archivo creado durante la práctica de ramas. |

## Comandos practicados

```bash
git checkout -b develop        # crear la rama de trabajo
git add README2.md
git commit -m "Agregar README2"
git checkout master
git merge develop              # integrar los cambios
```
